# Log de Sesiones

Una entrada por sesión de trabajo significativa. Complementa `docs/PROJECT.md`, no lo reemplaza: acá va el detalle por sesión, en PROJECT.md las decisiones arquitectónicas (ADRs) y la fuente de verdad del proyecto.

Convenciones:
- Nombre de archivo: `YYYY-MM-sesion-N.md` (mes y número correlativo de sesión).
- Brevedad: una sesión entra en pantalla y media.
- Las decisiones grandes se registran también como ADR en `docs/PROJECT.md`.

Secciones (usar las que apliquen, no todas son obligatorias):
- **Decisiones operacionales**: workflow, herramientas, proceso.
- **Decisiones editoriales**: contenido, voz, curaduría.
- **Decisiones técnicas**: implementación, librerías, patrones.
- **Sprints deployados**: qué se entregó, con número de ADR si corresponde.
- **Próximo (próxima sesión)**: qué arranca la próxima vez.
- **ADRs agregados en esta sesión**: números.
